# Security Policy

## Supported Versions

Security fixes are applied to the latest version of DevAid on the `main` branch.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub Issues or public discussions.

If GitHub private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option in the repository's **Security** tab.

If private vulnerability reporting is unavailable, contact the repository maintainer privately through their GitHub profile:

https://github.com/11kzpk-1906

When reporting, include:

- A clear description of the potential vulnerability.
- The affected DevAid version, commit, or file.
- Steps to reproduce the issue, where safe to share.
- The potential impact and any suggested mitigation.

Please avoid including real credentials, personal data, or other sensitive information in your report.

## What to Expect

The maintainer will review reports and may ask for additional information to understand and verify the issue. Please allow reasonable time for investigation and a fix before sharing details publicly.

DevAid is provided as-is. Its static diagnostics are guidance, not a security guarantee, and they do not replace a professional security review.
