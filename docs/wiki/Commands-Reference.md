# Commands Reference

Use `devaid --help` for the installed command tree and `devaid COMMAND --help` for options.

Core workflows include `doctor`, `analyze`, `deps`, `backup`, `backup-verify`, `restore`, `snapshot`, and `snapshot-compare`.

Newer local-first diagnostics include `sbom`, `secret-scan`, `sarif`, `licenses`, `git-review`, `coverage`, `history`, `history-compare`, and `explore`. Use `--path PATH` where applicable. Use `coverage --run-tests` only when you explicitly want DevAid to execute pytest under coverage.py.
