# Installation

Download the latest stable release from GitHub Releases. The current README distinguishes the development version from the latest published stable version.

Supported standalone archives:
- Windows x64: `devaid-windows-x64.zip`
- Linux x64: `devaid-linux-x64.zip`
- macOS Apple Silicon: `devaid-macos-arm64.zip`

Extract the archive and run `devaid --help`. Verify downloads with the accompanying SHA-256 checksum file when available. For source installation, use Python 3.11+ and uv as described in the repository README.
