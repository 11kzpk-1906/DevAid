# Contributing

Before opening a pull request:

1. Check for an existing issue.
2. Describe the problem and expected behavior.
3. Add tests for new behavior.
4. Update the README or documentation when commands change.
5. Run `uv run pytest`, `uv run ruff check .`, and `uv run python scripts/check_markdown_links.py`.

Follow the repository CODE_OF_CONDUCT.md and CONTRIBUTING.md. Keep changes focused and never include credentials in examples.
