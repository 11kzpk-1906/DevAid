# Security and Privacy

DevAid favors local, read-only analysis. Secret scanning redacts matched values and applies file-size and file-count limits. It is heuristic and cannot guarantee detection.

Do not upload real credentials or private keys to issues. Review backup contents before sharing. Git review never stages, commits, resets, checks out, or modifies files.

Third-party plugins execute code with your permissions and are not sandboxed. Install only trusted plugins. Network-dependent vulnerability checks are documented separately.
