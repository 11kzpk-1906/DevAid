# Getting Started

DevAid is a local-first developer toolkit. Start by installing the standalone CLI or running from source.

## First run

1. Install DevAid for your operating system.
2. Run `devaid --help`.
3. Run `devaid version`.
4. Inspect a project with `devaid doctor --path PATH` or `devaid analyze --path PATH`.

DevAid's local diagnostics do not upload project source. Network-dependent features are explicitly documented.
