## Guides
Start with Getting Started, then choose the installation method for your platform. Use the command reference for supported CLI syntax and troubleshooting for common setup problems.

## Reference
The CLI is the authoritative source for command behavior. Run `devaid --help` and `devaid COMMAND --help` in the installed version. Features marked planned are not available commands.

## Development
See the repository's CONTRIBUTING.md and architecture documentation before changing the CLI or browser utilities.

## Project information
DevAid prefers local analysis, bounded file reads, and explicit network access. Third-party plugins execute code with the user's permissions and are not sandboxed.
