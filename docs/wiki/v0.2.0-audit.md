# Wiki documentation audit — v0.2.0

## Audit status

The GitHub Wiki has no retrievable Home.md or Getting-Started.md page at the time of this audit. No page content was available to validate, so this is a repository-backed documentation baseline rather than a claim that existing Wiki pages were edited.

## v0.2.0 command verification

The v0.2.0 CLI source and tests confirm these user workflows:
- `devaid update-check`: checks the latest stable release; it does not install updates.
- `devaid backup [PATH] --output FILE`: creates a local ZIP backup.
- `devaid backup-verify ARCHIVE`: verifies the backup manifest and checksums.
- `devaid restore ARCHIVE --destination PATH`: restores to a new destination and refuses overwrites.
- `devaid snapshot [PATH] --output FILE`: records file paths, sizes, and hashes.
- `devaid snapshot-compare BEFORE AFTER`: compares added, modified, deleted, and unchanged files.
- `devaid welcome`: offers the guided first-run menu.

## Installation and platform claims

The release workflow builds Windows x64, Linux x64, and macOS ARM64 standalone archives. The README distinguishes the development version from the latest published stable release. Platform-specific limitations are documented in docs/platform-support.md and docs/standalone-installation.md.

## Corrections and future-feature policy

- Do not describe update-check as an automatic updater.
- Do not imply backup includes ignored secrets or caches; review exclusions before sharing an archive.
- Do not imply restore overwrites an existing destination.
- Do not describe snapshots as source backups; they contain metadata and hashes.
- Keep roadmap features clearly marked planned until the command exists and CI verifies it.
