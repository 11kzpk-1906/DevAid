DevAid Documentation

Free, local-first diagnostics and browser utilities for everyday development work.

DevAid is early-stage software. Findings are heuristic guidance, not guarantees. CLI diagnostics are read-only and do not upload project source.

Install

git clone https://github.com/11kzpk-1906/DevAid.git
cd DevAid
uv sync --extra dev
uv run devaid --help

CLI commands

  • uv run devaid package-doctor . — package manifests and lockfiles.
  • uv run devaid python-doctor . — Python project conventions.
  • uv run devaid javascript-doctor . — Node.js metadata and hygiene.
  • uv run devaid report . --format markdown --output report.md — Markdown report.
  • uv run devaid report . --format json --output report.json — JSON report.
  • uv run devaid doctor . — run all CLI diagnostics.

Browser tools

Open DevAid Web for the JSON Inspector, Regex Tester, URL Encoder / Decoder, Text Diff, YAML Validator, Docker Compose Checker, GitHub Actions Workflow Checker, and GitHub Repository Health Checker. Inputs are processed locally in your browser. The YAML parser library loads from jsDelivr, but YAML content stays in the browser.

Text Diff

Paste original and modified text into the two panels and select Compare text. Added lines are marked with a plus sign, removed lines with a minus sign, and unchanged lines remain neutral. The result can be copied. This is a line-based comparison, not a syntax-aware or character-level diff. To keep browser memory use bounded, very large comparisons are rejected with a clear message.

YAML Validator

Paste YAML and choose Validate YAML to parse it. A successful parse is shown as JSON. Choose Format YAML to format valid YAML, or copy the parsed JSON result. The tool uses the js-yaml parser loaded from jsDelivr; an internet connection is needed to load that library, but the YAML input is not uploaded.

Docker Compose Checker

Paste a Compose YAML file and select Check Compose file. DevAid checks common structural requirements and highlights potential configuration and security concerns. This is heuristic guidance, not full Docker Compose schema validation; use docker compose config for authoritative validation with Docker installed.

GitHub Repository Health Checker

Enter a public GitHub repository URL and select Scan repository. The read-only public API scan checks repository metadata, a recognized license, README, contribution guide, code of conduct, security policy, issue templates, and workflow files. Contribution guides are detected at the repository root, .github/, or docs/; security policies and codes of conduct are detected at the root or in .github/. It produces a copyable findings report. Branch protection and private security settings cannot be reliably inspected without authorization, so they are explicitly marked as not verified rather than missing. GitHub API rate limits apply.

GitHub Actions Workflow Checker

Paste a workflow file and select Analyze workflow. The checker reviews trigger presence, jobs and steps, permissions, action SHA pinning, untrusted event interpolation in run commands, pull_request_target risks, and job timeouts. It provides heuristic guidance only; it does not execute workflows or contact GitHub. Findings can be copied as a text report.

Development

uv sync --extra dev
uv run ruff check .
uv run pytest
node --check web/app.js

Limitations

  • Static checks can produce false positives or miss issues.
  • Python and JavaScript checks do not install dependencies or execute project scripts.
  • The browser MVP does not execute the Python CLI or upload project folders.
  • Text Diff compares lines and caps the comparison matrix size.
  • YAML tools load js-yaml from a public CDN; YAML content is parsed locally and is not transmitted.
  • Docker Compose Checker performs heuristic checks only and does not replace Docker Compose validation.
  • GitHub Actions Workflow Checker performs static heuristic checks only; it does not execute workflows or replace GitHub's validation and security controls.
  • Repository Health Checker uses GitHub's unauthenticated public API; branch protection and private security settings are not verified, and API rate limits apply.
  • Package-manager coverage currently focuses on common Python and Node.js lockfiles.

Never publish real credentials or confidential project data in public issues.
